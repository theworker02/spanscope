# spanscope

Span filesystem scope paths across POSIX and Windows conventions.

**Site:** https://theworker02.github.io/spanscope/

## Install / run

```bash
git clone https://github.com/theworker02/spanscope.git
cd spanscope
node src/cli.js
node --test
```
